About confix

confix is a small, dependency-free bash script that edits configuration files in place — properties, ini, yaml-ish, anything with keyseparatorvalue lines. Point it at a file, give it one-line commands, done.

Command grammar

key=valueupdate an existing key (no-op if absent)
>key=valueset the key, appending it if absent
>keyuncomment an existing key
<keycomment out an existing key
!keydelete the key's line (active or commented)

The separator (default =) and comment char (default #) are configurable. Commands always split key/value on the first =, independent of the file separator.

About this demo

The real tool is the bash script; this page reproduces its edits in JavaScript so it can run entirely client-side (nothing is sent anywhere). The port is validated against the bash script's own output.
